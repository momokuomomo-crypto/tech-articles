# 記事の未処理事項

## 完了

- 文章規範の適用（01〜04すべて）。両チェッカーが0件
- 一記事完結への対応。各記事の冒頭に、その記事だけで足りる前提を置いた

## 保留中の判断

- 「一文ごとに改行する」を適用するか。QiitaとZennは単一の改行を `<br>` として
  表示するため、見た目が変わる。`npm run zenn:preview` で確認してから決める
- 太字をどこまで許すか。現在は「定義される用語だけ」に絞ってある（01は2箇所、
  02は4箇所、03と04は各1箇所）

## 公開後にやること

記事間リンクは `(@NN)` マーカーで書いてある。公開後に `articles.config.json` の
`qiitaUrl` / `zennUrl` を埋めて `npm run sync` すると、プラットフォームごとの
実URLへ解決される。URL未設定の間はリンクを外して表示テキストだけ残すため、
踏めないリンクが公開面に出ることはない。
